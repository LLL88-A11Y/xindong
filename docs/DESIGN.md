# 心懂

懂你心理的决策伙伴：帮你想清楚、选得对。基于 LangGraph，部署在 EdgeOne Makers。

## 底层原则

> 不要试图根据以往他人的数据来确定一个人的心中所想，每个人都不可能是一成不变的，不要把之前的心理问题当做下次心理预测的参考。

落实方式：
- 所有提示词都以 `CORE_PRINCIPLE` 开头（`agents/chat/_prompts.ts`）。
- `enforceEvidence()`（`agents/chat/_graph.ts`）：情绪/思维陷阱的解读必须引用用户**这一次**的原话，否则在代码层直接丢弃。
- 情绪解读只存在于本轮（`turn`），每轮结束清空，从不喂回给下一轮的分析。
- 「不准」：用户否定过的解读在这次对话里不再出现（思维陷阱按类型，情绪按"同一句话 + 同一个情绪"），只用来少说、从不交给模型，新对话清零。
- 危机时不做任何情绪/思维解读，低落时不做"换个角度"的纠偏（代码层清空）。
- 危机分两种（分析员的 `at_risk`）：用户本人有危险 → `crisis`（热线）；用户转述的别人有危险（"我朋友说不想活了"）→ `crisis_other`（固定文字：怎么帮 TA + 可复制的回复）。两段固定文字互相兜底："如果其实是别人说的 / 如果其实是你自己"。分析员调用失败时默认按用户本人处理。危机关键词兜底不需要模型，额度用完也能给出热线。
- 打分表每格标注依据（`said` 用户说过 / `guess` 估计）；大部分是估计时，前端不显示「领先」。
- 不把用户不同时候说的话串成因果（提示词，代码无法判断）。

## 第二期：关系模式 + 聊天截图

- 「处理关系」模式（`relation` 节点）：我听到的 → 换到对方那边看看（只用"也许""可能"，不给对方贴标签）→ 可以这样说（非暴力沟通的回复草稿，`> ` 开头，页面上带「复制」按钮）。
- 聊天截图在**浏览器里**识别（`src/ocr.js`，tesseract.js + 简体中文），图片不上传、不花模型额度：先按颜色找气泡，再逐个识别；气泡贴右边是"我"，贴左边是"对方"。识别结果给用户看、可修改，确认后才放进输入框。
- 网关的模型在免费额度下不能读图片（实测连 80×32 的小图都报额度不足），所以没用模型识图。
- 识别组件放在 `public/ocr/`（约 9MB，用户第一次识别时下载约 6MB），不走外部 CDN。升级 tesseract.js 后运行 `node scripts/copy-ocr.mjs`。
- 聊天记录里"对方："开头的行是别人的话：不能当用户情绪的依据，也不触发用户的危机关键词（`ownWords()`）。

## 第三期：记住的事（长期记忆）

按底层原则设计：**心懂不会悄悄拿过去的事推测现在**。
- 只在开完会、或聊完一段关系之后问一句"要我记住这件事吗？"（倾诉和危机从不问，一个对话只问一次）。用户点「记住」才记，标题可以改。
- 只记标题（这件事本身），不记情绪和心理状态；只存在这台设备的浏览器里（`localStorage` 的 `xindong_memory_v1`），服务器不保存。
- 过去的事由**页面**列出来（新对话的欢迎页"上次聊到的事"），不交给模型。用户点「接着聊」，标题才放进输入框，发不发由用户决定。
- 「我已经解决了这个问题了」：这件事不会再出现在"上次聊到的事"里（用户的原话：解决了就不拿之前的问题来做参考）。
- 右上角「记得的事」可以查看、标记解决、删除、全部删除。

## 模型

默认 `@makers/deepseek-v4-flash`（会先"思考"再回答）。会议里的四个角色关掉思考（`thinking: { type: 'disabled' }`，`agents/_model.ts` 的 `seat`）：快约 2 秒/次、少约 20% token。分析员、打分员和心懂本人保留思考。

## 流程（第一期）

```
用户消息 → analyze（安全 + 模式 + 情绪 + 决策信息）
  ├─ 高风险 → crisis（固定的求助信息：12356 / 110 / 120）
  ├─ 倾诉 / 关系 / 闲聊 → listen
  ├─ 决策信息不足 → clarify（追问 1~2 个问题）
  ├─ 已开过会，追问 → followup
  └─ 开会 → score → 理性派 → 感性派 → 第十人 → 验尸官 → 主持人总结
```

选项 ≥2、在乎的方面 ≥2、这组选项还没开过会 → 代码规定一定开会（不交给模型）。
会议角色发言第一行写"倾向：选项"，后端拆成 `stance` 事件，前端显示为徽章和席位条。
